# forty-hadith

Links behind the QR codes in *The Forty Hadith of Imam al-Nawawī* by Mousa Taher.

Each QR code in the book opens `https://mousastaher-maker.github.io/forty-hadith/NN/`
(01 to 42), which forwards to a recitation video.

## Changing where a code goes

If a video is removed, or you want a different recitation:

1. Open the folder for that hadith (for example `07`) and click `index.html`.
2. Click the pencil icon (Edit).
3. Replace the old YouTube address with the new one. It appears **four times** in the file, so change every one.
4. Click **Commit changes**.

The QR code in every printed copy will now open the new video, usually within a minute.
Also update the matching line in `index.html` if the title changes.

Do not rename or delete this repository, or the numbered folders: the printed codes depend on them.
